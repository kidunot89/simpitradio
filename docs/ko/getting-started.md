# 시작하기

설치하고, 어떤 키를 들을지 알려주고, 말하면 됩니다. 그 뒤로는 모두 선택
사항입니다.

![상태 탭이 열린 SimPitRadio 창](images/window.png)

## 설치

[릴리스 페이지](https://github.com/kidunot89/simpitradio/releases/latest)에서
설치 프로그램을 내려받아 실행하세요. Windows가 경고를 띄웁니다. 빌드에 코드
서명이 없어서 SmartScreen이 "Windows의 PC 보호"를 표시하므로 **추가 정보 →
실행**을 선택해야 합니다. 서명되지 않은 설치 프로그램은 원래 그렇게 보이며,
서명에는 이 프로젝트가 쓰지 않는 비용이 듭니다.

설치 과정에서 묻는 것은 **언어** 하나뿐이고, Windows의 언어가 미리 선택되어
있습니다. 이것으로 세 가지가 한꺼번에 정해집니다. 창의 표시, 음성 모델, 그리고
엔지니어가 말하고 알아듣는 언어입니다. 나중에 언어 탭에서 바꿀 수 있습니다.

**의도적으로 관리자 권한으로 설치됩니다.** Windows는 보내는 쪽보다 높은 권한으로
실행 중인 프로그램을 향한 주입 키 입력을 버리고, 시뮬레이터는 대개 상승된 권한으로
실행됩니다. 이것이 없으면 모든 것이 동작하는 것처럼 보이지만 게임에는 아무것도
도달하지 않습니다.

### 첫 실행에서 두 가지를 내려받습니다

설치 프로그램에는 큰 것이 들어 있지 않으므로, 처음 열 때 다음을 받을지 묻습니다.

- **음성 모델**(약 250MB). 목소리를 글자로 바꾸는 것입니다
- 엔지니어의 **보이스 팩**(약 45MB). 사용하는 언어로 공개된 것이 있다면

둘 다 한 번뿐입니다. 모델은 설치 폴더 바깥에 있어서 업데이트할 때 다시 받지
않습니다. "나중에"를 고르면 언어 탭과 설정 탭에서 언제든 같은 일을 할 수
있습니다.

포터블 빌드에는 설치 프로그램이 없고 따라서 언어 질문도 없으므로, 대신 첫 실행
때 같은 것을 묻습니다.

## 키 고르기

**설정 → 트리거.** *키를 누르세요…* 를 누른 다음 원하는 키를 누릅니다.

![설정 탭의 트리거 영역](images/trigger.png)

키는 **지나가는 길에 삼켜지므로** 게임은 그 키를 전혀 보지 못합니다. 게임이 이미
쓰고 있는 키를 지정해도 아무것도 깨지지 않습니다. 기본값이 `F13`인 이유는 대부분의
키보드에 이 키가 없고, 다른 무엇도 그것을 듣고 있지 않기 때문입니다.

**휠 버튼도 마찬가지로 됩니다.** **휠 버튼** 행에서 *버튼을 누르세요…* 를 누른
다음 원하는 버튼을 누릅니다. SimPitRadio는 휠을 게임에서 빼앗지 않고 그대로 열어
두므로, 시뮬레이터는 그 버튼을 포함한 모든 버튼을 계속 읽습니다. 키를 누를 때와
똑같이, 버튼을 누른 채로 말하면 됩니다. 둘 다 동시에 무장되어 있으므로 두 가지를
모두 지정해 두고 더 가까운 쪽을 쓰면 됩니다.

다른 방법은 휠 자체의 소프트웨어나 [JoyToKey](https://joytokey.net/)를 쓰는
것입니다. 버튼에 `F13`을 지정하고 여기에 `F13`을 지정하세요. 휠에서 이미 신뢰하는
소프트웨어가 돌고 있거나 SimPitRadio가 장치를 열지 못할 때 쓸 만합니다.

## 마이크 설정하기

**오디오 → 마이크.** 입력을 고르고 트리거를 누른 채 레벨 바를 보세요. 게인이
적용된 *뒤*의 신호, 즉 음성 모델이 실제로 받는 것을 보여줍니다. 4분의 3 근처에서
정점을 찍도록 맞추세요.

![오디오 탭](images/audio.png)

**출력은 시뮬레이터와 같은 장치로 두지 마세요.** 엔지니어, 코치, 녹음 신호음이
모두 여기서 재생됩니다. 게임과 같은 출력으로 향하게 하면 신호음이 녹음에 섞여
들어갑니다.

**4초 녹음 후 받아쓰기**를 누르면 무엇으로 들렸는지 확인할 수 있습니다. 테스트
중에는 어디에도 글자가 입력되지 않습니다.

## 말해보기

트리거를 누른 채 하고 싶은 말을 하고, 놓습니다.

1. 키가 삼켜집니다.
2. 녹음이 **즉시** 시작됩니다. 채팅창이 열리기 전이므로 처음 수백 밀리초에 한
   말이 사라지지 않습니다.
3. 채팅 키가 게임의 채팅창을 엽니다.
4. 놓으면 클립이 여러분의 CPU에서 도는 음성 모델로 갑니다.
5. 글자가 입력되고 전송 키가 눌립니다.

상태 탭에는 후크가 무엇으로 무장되어 있는지, 트리거가 마지막으로 언제 보였는지가
표시됩니다. *마지막 트리거*가 갱신되지 않는다면 문제는 받아쓰기가 아니라 키나
후크입니다.

## 뭔가 잘못됐을 때

**먼저 상태 탭을 보세요.** 앱이 무엇을 인식하고 있는지 보여주는 유일한
곳입니다. 무장된 키, 포커스된 실행 파일, 사용 중인 프로필, 그리고 실시간 로그.

![상태 탭의 로그](images/log.png)

- **아무것도 입력되지 않음.** [아무것도 입력되지 않음](text-chat.md#아무것도-입력되지-않을-때) 참고.
- **아무 말도 하지 않음.** [아무 말도 하지 않음](engineer.md#아무-말도-하지-않음) 참고.
- **아무것도 그려지지 않음.** [아무것도 그려지지 않음](coaching.md#아무것도-그려지지-않을-때) 참고.

로그는 파일로도 기록됩니다. **상태 → 로그 폴더 열기**로 갈 수 있으며, 문제를
보고할 때 가장 먼저 첨부할 만한 것입니다.
