# コーチ

誰かを選んで研究の対象にすると、サーキットのセグメントを走り終えるたびに、パネル
があなたのラインを相手のラインと並べて描き、コーチが何を変えるべきかを教えてくれ
ます。

> *トサ、頂点でまだブレーキを残していたのでコーナー中間の速度を失いました。相手は
> より遅い頂点を取るので、立ち上がりが早くまっすぐになります。*

時計だけでなくペダルとステアリング、そしてギアまで読むので、言うことはタイミング
モニターの言い換えではなく原因です。タイヤをロックさせたりコースから外れたりすれ
ば、まだその感触が残っているうちに、すぐそう言います。

コーチはエンジニアではありません。独自の声、独自の音量、独自の通知を持ち、どの読
み上げもその声で行われるので、二人のどちらが話しかけているのか常に分かります。
**コーチング → 担当** で設定します。*エンジニアをコーチとして使う* にチェックを入
れれば、声を一つにまとめることもできます。

## クイックスタート

1. 3、4 周走ってください。コーチはまずサーキットを把握します。
   [セグメントはどこから来るのか](#セグメントはどこから来るのか) を参照。
2. トリガーを押しながら **「コーチして」** と言います。
3. **「P3 に注目して」**、あるいは自分のベストと比べるなら **「自分に注目して」**
   と言います。
4. 走ります。コーナーごとにパネルがそれを描き、コーチが話します。

ここには、セッション前に入れておくチェックボックスはひとつもありません。コーチン
グは欲しいときに声で頼み、そう言えば下がります。コーナーの途中で話しかけられたい
かどうかは、周回ごとに決めることだからです。

## 話しかける

以下の言い回しのほとんどは 2 語以上なので、前にコーチの名前を付けるかどうかは自由
です。例外は「研究して」と「見ていて」で、どちらも単独では 1 語であり、そのあとに
続く言葉はすべてドライバーの名前として扱われるため、どちらもコーチの名前を前に付
ける必要があります。*チーフ、エストルを研究して。*

| したいこと | 言い方 |
| --- | --- |
| コーチングを始める | **コーチして** · *導いて* · *ラインを見せて* · *コーチング開始* |
| 止める | **コーチング終了** · *コーチングをやめて* · *ラインはもういい* |
| 比較する相手を選ぶ | **エストルを研究して** · *P3 に注目して* · *LMP2 のトップを見ていて* |
| 自分のベストと比べる | **自分に注目して** · *自分のベストを研究して* · *自分の理想ラップに注目して* |
| 自動選択に戻す | **既定の注目** · *自動で注目* |
| 何が動いているか聞く | **どのコーチングが有効** |
| 今のコーナーを描き直す | **さっきのコーナー** · *あのコーナー* |

終わりのない引数を取る 1 語の言い回しは、そのままではセッション向けのメッセージを
飲み込んでしまいます。「に注目」と「を見ていて」は単独でも安全なだけの長さがあり、
だからこそここに挙げられています。

**ライバルを選ばなくても構いません。** *自分* に注目するよう頼めば、2 本目のライン
はあなた自身の理想ラップになります。実際に走った 1 周ではなく、各コーナーでの自己
ベストを組み合わせたものです。誰もいない練習セッションにも相手はいますし、コース
上に他に誰もいないときには、それが正直な相手です。

## セグメントはどこから来るのか

**サーキットはデータベースからではなく、あなた自身の走行から割り出されます。** セ
ッション中に走られたすべてのラップ — あなたのものも他の全員のものも — が 5 メート
ル間隔のグリッドにまとめられ、各点を通過したものの中央値が路面の位置になります。
ある点が信用されるには 4 周が通過する必要があり、そもそも路面が作られるにはサーキ
ットの半分が把握されている必要があります。

だからこそ、どのシムのどのコースでも、誰もカタログ化していないコースでも動きます。
カタログがあるところでは名前が付きます。「7 コーナー」ではなく「トサ」のように。
無いところでは番号になり、それ以外はまったく同じように動きます。

このまとめ上げは 2 回行われます。1 回目は比較する路面がまだ無いので、車自身の向き
からコースを横切る方向を割り出します — ところが車が左右に振られているとき、その向
きは決して路面に沿っていないので、答えはどの周でも同じ方向にずれます。いったん路
面ができれば、その路面自身の方向が正しい基準になり、2 回目がそれを補正します。3 メ
ートル幅で振りながら走った合成の円コースでは、1 回目の路面は実際の位置から 2.5 メ
ートルずれていました。

### 何がセグメントになるのか

セグメントとは、コーナーに、その進入路と脱出路を足したものです。それがあなたの走
る単位だからです。

- **進入路** はブレーキを踏んだ地点まで遡り、上限は 250m です。固定の長さではあり
  ません — 遅く踏めば、セグメントも遅く始まります。
- **脱出路** は出口から 50m 先までで、車がどこへ出てどこを向いていたかが分かるだけ
  の長さです。
- **1 回のブレーキで抜ける 2 つのコーナーは 1 つのセグメントです。** クラブとベイル
  は走るうえで一つのものであり、見るうえでも一つです。セブリングのヘアピン 2 つも
  同じです。
- **全開で抜けるコーナーは飛ばされます。** スロットル 90% を超えたまま抜けるコーナ
  ーには、動かすべきブレーキングポイントも、持ち込むべき進入速度もないので、直線と
  して扱われます。地図には残り、名前も保たれます — ただ目の前に出されないだけです。
  *何をコーチングするか* の下にある **直線と全開区間** を有効にすれば、それでも表示
  されます。

まとめることも飛ばすことも、基準となるラップが必要です。それが無ければ、2 つのコー
ナーが実は 1 つだと判断する根拠がコーチには無いので、離したままにします。

## 何を言うのか

**コーチング → 何をコーチングするか → ドライバーのレベル** が、どこまで言うかを決
めます。3 つのレベルはどれも同じコーナーを見て同じ欠点を見つけます。落とすのは所見
ではなく、節です。

| レベル | 得られるもの |
| --- | --- |
| **初級** | すべて — 何が良かったか、何が悪かったか、その原因、そしてどうするか |
| **中級** | 結果の説明なし。欠点と対処だけ。頂点でのアンダーステアが立ち上がりに何をするかは知っている前提 |
| **上級** | 対処もなし。良かったことと悪かったこと。「もっと早くブレーキを」と言われるのは、たいてい既に知っていることを言われることです |

黙っているのが意図的だと分かるように、測っているものとその閾値をいくつか挙げます。

- 2 つの速度の差は、言及に値するまでに毎秒 0.5 メートル — 時速 2 キロ未満 — 必要で
  す。それ以下なら二人は同じことをしており、差はラップがたまたまどこで標本化された
  かにすぎません。
- 路面を使い切るとは、半幅すべてではなく 85% に達することを指します。毎周きっちり
  白線の上にタイヤを置くドライバーは、トラックリミットを取っているドライバーです。
  勝つラインは、近づくラインです。
- ペダルは 5% の踏み込みで踏まれたことになり、ステアリングは切れ角の 5% で切られた
  ことになります。シムのペダルとステアリングが正確にゼロで静止していることは、めっ
  たにありません。

## 通知

**コーチング → 通知** で、コーチの 3 種類の読み上げをそれぞれ個別に切り替えられま
す。

- **セグメント分析** — コーナーごとの読み上げ。
- **その場でのミス** — ロックしたタイヤ、コースアウト。ためておかず、すぐに言いま
  す。
- **相手が速かったところ** — 1 周に 1 回。

これらは意図的にエンジニアの動作とは別になっています。コーチングを絞ってもスポッ
ターまで絞られないようにするためです。3 つとも動くにはコーチモードが必要で、コーチ
ングを頼むまではどれも何も言いません。

## ダイアグラム

![パラボリカ、あなたのラインとライバルのライン](images/segment_parabolica.png)

モンツァのパラボリカを、実際のセッションから描いたものです。淡い部分がブレーキン
グ、濃い部分がパワーオン。丸はそれぞれの車がブレーキを踏んだ地点、三角はスロット
ルに戻った地点で、進行方向を指しています。

パネルは 3 つのダイアグラムを収めています。1 つが入ってきて、1 つが真ん中で語られ、
1 つが出ていきます。位置が進み具合なので、一目でコーチがどこまで来たか分かります。
ダイアグラムはゲームの上に浮かび、背後には何もありません。

あなたのラインは **オレンジから赤**、ライバルは **インディゴからシアン** で描かれ
ます。色相が誰のラインかを示し、**明度が足の動きを示します** — ブレーキで最も淡く、
パワーオンで最も濃く。どちらのラインも破線で、2 つのパターンは半周期ずらしてありま
す。二台がまったく同じラインを取ったところでも、一方が他方を隠すのではなく、互い
の隙間から覗くようにするためです。それぞれのドライバー名は、ダイアグラムの最も空
いている角に、そのドライバー自身の色で書かれます。どちらの色がどちらだったかを覚
えておく必要はありません。

路面は 2 本の白線に挟まれた濃いリボンで、レーシングラインから推測したものではな
く、シム自身のコース端の読み取りから取っています — だから白線の外に置いたタイヤ
は、白線の外に描かれます。

![ダイアグラムの待ち行列](images/diagram_queue.png)

3 つのダイアグラム。1 つが入ってきて、語られているものが真ん中、1 つが出ていきます。
真ん中のダイアグラムが、今コーチが話しているものです。

### 運転席から見た様子

![イモラのコックピットの上に描かれたトサと、その手前のコーナー](images/incar_tosa.jpg)

イモラ、セッションの途中。ダイアグラムが 2 つ同時に出ています。走り終えたばかりの
コーナーと、その 1 つ前のコーナーで、どちらも番号ではなく、サーキットのカタログか
ら自分の名前を名乗っています。それらは背後に何も置かずゲームの上に載るので、画面
に加わるのは描画そのものだけです。

![両者のラインとその速度が描かれたデイトナのコーナー](images/incar_daytona.jpg)

誰もカタログ化していないサーキットでの同じもの。コーナーは名前ではなく `T5` と呼ば
れ、それ以外はすべてまったく同じように動きます — シム自身のコース端の読み取りから
取った路面、どちらも相手を隠さないよう破線にしてずらした 2 本のライン、そして進入・
クリッピングポイント・立ち上がりの速度です。

**コーチング → セグメントダイアグラム** で位置、大きさ、不透明度、そして待ち行列の
流れる向きを決めます。**パネルを表示** を押すとサンプルのコーナーが 3 つ出るので、
好きな場所へドラッグし、実物に合わせて大きさを決められます。

ボーダーレスまたはウィンドウで動いているゲームの上に描かれます。排他的フルスクリ
ーンの上には何も描かれません — それは設定ではなく、表示モードの性質です。

## トレイルブレーキング・トレーナー

ブレーキング中にタイヤがグリップの限界に達するたび、ピアノの音が鳴ります。ブレー
キを放す動作が、後からラップタイムで推し量るものではなく、耳で聞けるものになりま
す。

ブレーキを放すことは、車の中で感覚から学ぶのが最も難しい動作です。ペダルはほとん
ど何も返してきませんし、目標は車が減速するにつれ、また舵が入るにつれて動きますし、
限界のはるか手前のまま 1 シーズンを過ごし、そうと気づかないこともあり得ます。連続
音ではなく、放す段階ごとに 1 音です — スリップを追い続ける音は、聞き流すことを覚え
るブザーになりますし、「今こうしろ」ではなく「今ここにいる」としか言えません。

| 聞こえるもの | 意味 |
| --- | --- |
| 下がっていく 3〜6 音 | きれいに放せています |
| 1 音、そして無音 | 放すのが速すぎました |
| まったく音がしない | 限界に達していません |
| 音階から外れた低い音 | タイヤがロックしました |

| したいこと | 言い方 |
| --- | --- |
| 始める | **ブレーキの練習** · *ブレーキの練習を始めよう* · *ブレーキトレーニング* |
| 止める | **ブレーキ練習を終了** · *ブレーキの練習をやめて* |

最初の数回のブレーキング区間で車の転がり半径を学習するので、どのクラスでも、ブレ
ーキバランスがどこにあっても働きます。**コーチング → トレイルブレーキング・トレー
ナー** で、セッションと一緒に有効になるかどうかと、音の大きさを設定します。音量が
コーチと別なのは、この二つが順番待ちではなく混ぜられるからです — 音は話されている
内容に重なって鳴りますし、音は気づかれさえすればよく、話は理解される必要がありま
す。

## 何も描かれない

**数周走ってください。** サーキットのある区間を 4 周未満しか通っていなければそこに
路面はありませんし、サーキットの半分未満しか把握されていなければ路面はまったくあ
りません。たいていはこれが答えです。

**シムが位置を公開しているか確認してください。** ラインは X/Z 座標とコース端から描
かれます。それらを公開しないシムでも、ラップタイム、ミス、音声での分析は得られま
すが、絵は得られません。[各シムでできること](engineer.md#各シムでできること) を
参照してください。

**排他的フルスクリーンでないか確認してください。** ボーダーレスかウィンドウのみで
す。

**実際に頼んだか確認してください。** コーチングはそう言うまで止まっています。始ま
るときには「コーチング」と返し、続けて誰と比較しているか、そしていくつのセグメン
トを把握しているか、あるいは「コースを学習中」のどちらかを伝えます。
