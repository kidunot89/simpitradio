# はじめに

インストールして、どのキーを待ち受けるかを教え、話しかける。これらのページに書
かれている他のことは、すべて任意です。

![ステータスタブを表示した SimPitRadio のウィンドウ](images/window.png)

## インストール

[リリースページ](https://github.com/kidunot89/simpitradio/releases/latest)からイン
ストーラーをダウンロードして実行します。Windows は警告を出します。ビルドにコード
署名がないため、SmartScreen が「WindowsによってPCが保護されました」と表示するので、
**詳細情報 → 実行** を選ぶ必要があります。署名のないインストーラーとはそういうも
のであり、署名にはこのプロジェクトが支出しないお金がかかります。

セットアップが尋ねるのは **言語** の一つだけで、Windows の言語があらかじめ選ばれ
ています。これで三つが同時に決まります。ウィンドウの表示、音声認識、そしてレース
エンジニアが話し、聞き取る言語です。あとから言語タブで変更できます。

**管理者としてインストールされます。これは意図的です。** Windows は、送信元より高
い権限で動作しているプログラム宛に注入されたキー入力を破棄します。シムは昇格して
実行されていることが多く、これがないと、すべて動いているように見えて、実際にはゲー
ムに何も届きません。

### 初回起動で二つのものがダウンロードされます

インストーラーには大きなものが入っていないので、初めて開いたときに次の取得を求め
られます。

- **音声モデル**（約 250MB）。あなたの声を文字にするものです
- エンジニアの **録音された音声**（約 45MB）。あなたの言語で公開されていれば

どちらも一度きりです。モデルはインストール先の外に置かれるので、更新のたびに取り
直すことはありません。「あとで」を選んでも、言語タブと設定タブでいつでも同じこと
ができます。

ポータブル版の zip にはインストーラーがなく、したがって言語の質問もないため、代わ
りに初回起動時に同じことを尋ねます。

## キーを選ぶ

**設定 → トリガー。** *キーを押してください…* を押し、使いたいキーを押します。

![設定タブのトリガーセクション](images/trigger.png)

キーは **通り道で飲み込まれる** ので、ゲームからは見えません。つまり、ゲームがす
でに使っているキーでも構いません。既定が `F13` なのは、たいていのキーボードにこの
キーがなく、他の何もそれを待ち受けていないからです。

**ホイールのボタンでも使えます。** [JoyToKey](https://joytokey.net/) でキーボード
のキーに割り当て、そのキーをここで登録してください。SimPitRadio がホイールを直接
読まない理由は[エンジニアのノート](engineer.md#シムごとの設定)にあります。ある
Fanatec のリムは 79 個の入力を列挙しながら、四つの異なるライブラリのどれを通して
も押下を一度も報告せず、Steam コントローラーを読むには Steam から取り上げるほかあ
りませんでした。

## マイクを設定する

**オーディオ → マイク。** 入力を選び、トリガーを押したままレベルバーを見てくださ
い。ゲイン適用 *後* の信号、つまり Whisper が実際に受け取るものを表示しています。
四分の三あたりでピークになるくらいを目安に。

![オーディオタブ](images/audio.png)

**出力はシムと同じデバイスにしないでください。** エンジニア、コーチ、録音キューは
すべてここから鳴ります。ゲームと同じ出力に向けると、ビープ音が録音に入り込みます。

**4秒録音して文字起こし** を押すと、何がどう聞こえたかを確認できます。テスト中はど
こにも文字は入力されません。

## 話してみる

キーを押したまま、言いたいことを言い、離します。

1. キーが飲み込まれます。
2. 録音が **すぐに** 始まります。チャットボックスが開く前なので、最初の数百ミリ秒
   に言ったことが失われません。
3. チャットキーがゲームのチャットボックスを開きます。
4. 離すと、クリップはあなた自身の CPU 上の Whisper に渡されます。
5. テキストが入力され、送信キーが押されます。

ステータスタブには、フックが何を armed にしているか、そして最後にトリガーが見えた
のはいつかが表示されます。*最後のトリガー* が更新されないなら、問題は文字起こしで
はなくキーかフックです。

![ステータスカード](images/status.png)

## さらに使いたくなったら

以下はどれも既定では有効になっていません。

| | |
| --- | --- |
| [テキストチャット](text-chat.md) | ディクテーションそのもの。プロファイル、送信前の確認、何も入力されないときの対処 |
| [エンジニア](engineer.md) | ラップタイムを読み上げ、並んだ車を知らせ、質問に答える名前つきの声 |
| [コーチ](coaching.md) | コーナーごとに、あなたのラインを相手のラインと並べて描き、何を変えるべきかを示します |
| [無線の音声](voice-chat.md) | セッションにいる他のドライバーの声を、近くにいる人だけ聞く |
| [ボイスパック](voicepacks.md) | エンジニアが話す声を録音する、あるいはインストールする |

## うまくいかないとき

**まずステータスタブを見てください。** アプリが何を認識しているかを示す唯一の場所
です。armed になっているキー、フォーカスされている実行ファイル、使用中のプロファ
イル、そしてライブのログ。

![ステータスタブのログ](images/log.png)

- **何も入力されない** — [何も入力されない](text-chat.md#何も入力されない)を参照。
- **何も話さない** — [何も話さない](engineer.md#何も話さない)を参照。
- **何も描かれない** — [何も描かれない](coaching.md#何も描かれない)を参照。

ログはファイルにも書き出されます。**ステータス → ログフォルダーを開く** でたどり着
けます。問題を報告するとき、まず添付する価値があるものです。
